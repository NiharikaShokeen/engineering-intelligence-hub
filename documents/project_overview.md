# TaskFlow

## What is TaskFlow?

TaskFlow is a task management platform that helps teams create, organize, assign, and track tasks.

## Main Features

- User registration and login
- Task creation
- Task assignment
- Task status tracking
- Notifications

## Technology Stack

Frontend:
React

Backend:
Node.js with Express

Database:
PostgreSQL

Authentication:
JWT

## Users

TaskFlow has two main types of users:

- Regular users
- Administrators

Regular users can create and manage their own tasks.

Administrators can manage users and view system-level information.
